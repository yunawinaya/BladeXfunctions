## What happened

PICKING run `2108089351207522305` (PI-20261008-1026, 2026-10-08 14:57:22) failed at
`add_node_LcxwYc7z` "Add Packing Data" with `Index 0 out of bounds for length 0`, so the Packings
for GD-2610-42 and GD-2610-43 were never created. Same failure on 10-01 (`2105552770156335105`,

parallel with `loop_PackingUpdates` (first node of its branch, added 2026-09-18). Loop state lives in
the run's shared context; when the add-node evaluates while the sibling loop is starting, it dies.
